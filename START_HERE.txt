Scraper Framework

Full documentation is in README.md.

After unpacking, the two main folders are:
- outputs - exported CSV, Excel files and downloaded images
- data    - framework files and adapter-related data

Before creating an adapter, fill ADAPTER_REQUEST.md.
For public image links, set:
- Domena zdjęć, for example https://mojadomena.pl/produkty/[marka albo kategoria]/[sku].[rozszerzenie]
- Marka, for example nazwa-marki

Setup:
1. Install Python 3.12 on Windows 64-bit.
2. Open a terminal in this folder.
3. Run:
   python -m pip install -r requirements.txt

Run:
   python run.py --adapter ADAPTER_NAME --export csv,excel

After a successful run, CSV/Excel exports are automatically enriched with:
- zdj1
- zdj2
- zdj3

These columns point to public image URLs like:
   https://mojadomena.pl/produkty/marka/SKU.jpg

Images are stored under:
   outputs/images/marka-lub-kategoria/SKU.jpg

Create adapter scaffold:
   python create_adapter.py --name shop_name --mode requests

Do not delete data/framework. It contains the protected framework runtime.
