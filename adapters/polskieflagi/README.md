# PolskieFlagi Adapter

Adapter dla kategorii:

https://www.polskieflagi.pl/kategoria-produktu/produkty/flagi-koscielne/

## Uruchomienie

```bash
python run.py --adapter polskieflagi --export csv,excel
```

Adapter korzysta z publicznego WooCommerce Store API i pobiera produkty z kategorii `Flagi Kościelne` (`category=24`).
